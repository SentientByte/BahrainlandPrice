# Bahrain Land Price Tool

A command-line utility for cleaning, exploring, and modeling land price data.

## Quick start (Windows)

Double-click `run.bat` or run it from a terminal. The launcher will reuse the
virtual environment in `.venv` when present or fall back to your system Python.

## Quick start (macOS/Linux)

Run the provided shell launcher:

```bash
./run.sh
```

The script prefers the project's `.venv` Python if available and otherwise uses
`python3` from your system. The application will prompt you to install
requirements on the first run.
